使用说明

多标签终端

点击标题栏的 + 新建终端。每个标签都是独立进程，可拖动排序、双击标题重命名、中键关闭。

快捷键

  • Ctrl+Shift+T新建终端
  • Ctrl+Shift+W关闭当前终端
  • Ctrl+Tab切换下一个终端
  • Ctrl+Shift+C复制选中文本
  • Ctrl+Shift+V粘贴

加密通道

页面加载时通过 ECDH P-256 生成临时会话密钥，经 HKDF-SHA256 派生 AES-256-GCM 密钥。 输入、输出、终端列表、背景图片全部以密文传输；每个数据包的附加认证数据都绑定到具体操作，防止跨接口重放。

安全提示

这是一个拥有 Shell 执行权限的管理工具。请只部署在可信网络中，并为 AstrBot WebUI 设置强密码。 可在插件配置中用 allowed_users 限制可访问的 WebUI 用户名。

会话保持

刷新页面后会自动恢复同一浏览器标签页创建的终端。关闭标签页不会立即结束 Shell，空闲超过配置时间后由后端自动回收。

平台说明

Linux / macOS 使用原生 PTY；Windows 使用 ConPTY（需要 pywinpty）。若依赖缺失，会退化为管道模式，交互式全屏程序可能无法正常显示。
