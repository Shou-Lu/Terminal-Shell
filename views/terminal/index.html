使用说明

一个页面，三个工作区

标题栏左侧的「终端 / 文件 / 状态」可以随时切换。所有功能共用同一条加密通道，不需要打开多个插件页面。

多标签终端

点击标题栏的 + 新建终端。每个标签都是独立进程，可拖动排序、双击标题重命名、中键关闭。

文件管理

在「文件」页浏览、上传、下载、预览和编辑文件，也可以新建文件夹、重命名或删除。访问范围受插件配置中的文件管理根目录限制。

设备状态

「状态」页实时展示系统运行时长、CPU、内存、负载与磁盘占用，并绘制成函数图。

快捷键

  • Ctrl+Shift+T新建终端
  • Ctrl+Shift+W关闭当前终端
  • Ctrl+Tab切换下一个终端
  • Ctrl+Shift+C复制选中文本
  • Ctrl+Shift+V粘贴

加密通道

页面加载时通过 ECDH P-256 生成临时会话密钥，经 HKDF-SHA256 派生 AES-256-GCM 密钥。 输入、输出、终端列表、文件内容、背景图片和设备状态全部以密文传输；每个数据包的附加认证数据都绑定到具体操作，防止跨接口重放。

安全提示

这是一个拥有 Shell 执行权限的管理工具。请只部署在可信网络中，并为 AstrBot WebUI 设置强密码。 文件工作区默认开放给所有已登录 WebUI 用户，如不需要请把根目录设置为专用目录或通过反向代理限制访问。

会话保持

刷新页面或从其他 AstrBot 页面切回插件页时，会自动恢复终端和最近输出。关闭标签页不会立即结束 Shell，空闲超过配置时间后由后端自动回收。

平台说明

Linux / macOS 使用原生 PTY；Windows 使用 ConPTY（需要 pywinpty）。若依赖缺失，会退化为管道模式，交互式全屏程序可能无法正常显示。
